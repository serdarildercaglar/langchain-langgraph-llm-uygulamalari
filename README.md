# langchain-langgraph-llm-uygulamalari
Bu eğitim programı, katılımcılara Büyük Dil Modellerini (LLM) etkin bir şekilde yönetmek (orkestrasyon) ve LangChain ile LangGraph framework'lerini kullanarak gelişmiş yapay zeka uygulamaları geliştirmek için gerekli teorik bilgiyi ve pratik becerileri kazandırmayı amaçlamaktadır.
